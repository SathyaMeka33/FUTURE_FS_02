TROUBLESHOOTING
================================================================================

ERROR: "GET https://your-frontend/... 400 (Bad Request)"
FIX: This is normal during initial requests. Wait a minute and refresh.

ERROR: CORS error - "No 'Access-Control-Allow-Origin' header"
FIX: 
1. Check backend CORS_ALLOWED_ORIGINS env var matches frontend URL exactly
2. Wait for backend to redeploy after saving env vars
3. Hard refresh browser (Ctrl+Shift+R or Cmd+Shift+R)

ERROR: "Cannot reach backend"
FIX:
1. Verify frontend can reach: https://leadflow-hsyp.onrender.com/api/
2. Check if API_BASE in script.js auto-detected correctly
3. Open DevTools Console and manually test:
   localStorage.setItem('crm_api_base', 'https://leadflow-hsyp.onrender.com/api')
   location.reload()

ERROR: 401 Unauthorized on login
FIX:
1. Clear token: localStorage.removeItem('crm_token')
2. Clear browser cache
3. Try logging in again with correct username/password
4. Use admin/admin if using default Django admin credentials
